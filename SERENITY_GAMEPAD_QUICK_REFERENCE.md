## 🎮 Button Functions

### Core Actions (Always Available)

| Button | Action | Description |
|--------|--------|-------------|
| **Y** (△) | Toggle Hub | Open/close Serenity Hub |
| **X** (□) | Breathing | Toggle breathing guide on/off |
| **LB** (L1) | Previous Track | Go to previous music track |
| **RB** (R1) | Next Track | Go to next music track |
| **LT** (L2) | Volume Down | Decrease music volume |
| **RT** (R2) | Volume Up | Increase music volume |
| **L3** (⬇︎) | Random Theme | Apply random visual theme |
| **R3** (⬇︎) | Fullscreen | Toggle fullscreen mode |
| **SELECT** | Button Hints | Show/hide button hints overlay |

### Hub Navigation (Only When Hub Is Open)

| Button | Action | Description |
|--------|--------|-------------|
| **A** (✕) | Confirm | Select/activate current item |
| **B** (◯) | Close | Close the Serenity Hub |
| **D-Pad ◀▶** | Switch Tabs | Navigate between hub tabs |
| **D-Pad ▲▼** | Navigate Items | Move up/down in lists |
| **L-Stick** | Navigate | Alternative to D-Pad |
| **R-Stick ▲▼** | Scroll | Scroll content in panels |

## 🎯 Common Actions

### Starting Your Session
1. **Start** → Open settings menu
2. **Y** → Open Serenity Hub
3. Navigate with **D-Pad** or **L-Stick**
4. **A** to select breathing technique
5. **X** to start breathing guide

### Adjusting Your Experience
- **LB/RB** → Change music tracks
- **LT/RT** → Adjust volume
- **L3 Click** → Try random visual theme
- **R3 Click** → Toggle fullscreen

### Quick Access
- **SELECT** → Show all button hints
- **Y** → Quick open/close hub
- **X** → Quick breathing toggle

## 💡 Pro Tips

1. **Press SELECT in Serenity Mode** to see the button hints overlay anytime
2. **Use L3 (stick click)** for quick theme changes during meditation
3. **LT/RT analog triggers** allow smooth volume adjustments
4. **Hub stays accessible** - press Y anytime to open/close
5. **All controls work together** - no conflicts with keyboard controls

---

## 🎨 Visual Button Hints In-App

When you press **SELECT** in Serenity Mode, you'll see a beautiful overlay showing:
- All available buttons
- Current actions
- Context-aware hints (changes when hub is open)
- Auto-hides after viewing

## 🔧 Where to Find This in Settings

1. Open **Settings** (Gear icon or **START** button)
2. Go to **Controls** tab
3. Click **🧘 Serenity Mode** subtab
4. View all controls with descriptions
