# Songs Folder

This folder contains all music tracks for Serenity Blocks.

## 🎵 Adding New Songs

1. Drop your `.mp3` files into this folder
2. Run from the project root: `node generate-songs.js`
3. The `songs.json` file will be automatically updated
4. Refresh the game - your new songs will appear!

## 🗑️ Removing Songs

1. Delete the `.mp3` file(s) you want to remove
2. Run from the project root: `node generate-songs.js`
3. The `songs.json` file will be automatically updated
4. Refresh the game - removed songs will be gone!

## 📄 songs.json

This file is **automatically generated** by `generate-songs.js`.

**DO NOT edit this file manually** - any manual changes will be overwritten when you run the generator script.

## Current Songs

Run `node generate-songs.js` to see the current list of songs.
