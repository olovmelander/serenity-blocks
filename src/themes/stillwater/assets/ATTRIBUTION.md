# Stillwater Asset Attribution

## Wandering troll (`troll.glb`)

A Nordic troll reconstructed from a single photo (`troll-source.png`) with
**TRELLIS.2-4B** (Microsoft, MIT) run locally on an RTX 5080, then rigged as a
biped and given a hand-authored **Walk** cycle in **Blender** (skinned glTF,
`Walk` clip; ~60k tris, vertex colours). It ambles back and forth across the back
of the glade, scene-lit and multiplied to a dark earthy green so it sits in the
John Bauer twilight mood. Distinct from the existing peeking billboard trolls
(which are 2D shader silhouettes). Self-generated asset — TRELLIS.2 is
MIT-licensed, so no third-party attribution is required.
