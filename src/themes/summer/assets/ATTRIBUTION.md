# Summer Trees Assets — Attribution

## Norway Spruce (`summer_spruce.glb`)
Low-poly Firewatch-style summer spruce. Source image generated via Gemini, reconstructed
from photo using **TRELLIS.2-4B** (Microsoft, MIT license) run locally via ComfyUI.
Auto-rigged with a 2-bone wind-sway armature using a Blender 5.x Python script
(`blender_rig_summer_trees.py`). 60-frame looping sway animation baked to GLB.

## Silver Birch (`summer_birch.glb`)
Low-poly Firewatch-style summer birch with white bark and round leafy canopy.
Source image generated via Gemini, reconstructed using **TRELLIS.2-4B**.
Auto-rigged and animated with custom wind sway cycle using Blender 5.x.

## Aspen (`summer_aspen.glb`)
Low-poly Firewatch-style summer aspen/deciduous tree with golden-green canopy.
Source image generated via Gemini, reconstructed using **TRELLIS.2-4B**.
Auto-rigged and animated with custom wind sway cycle using Blender 5.x.

## Reference
Visual reference: Swedish midsummer lakeside scene (low-poly Firewatch aesthetic).
Pipeline: Gemini image → TRELLIS.2-4B (GGUF Q8_0) → Blender 5.1.2 rig → GLB.
