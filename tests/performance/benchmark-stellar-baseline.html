Stellar Drift Phase 0 Baseline Harness

1) Launch Runtime

After load, switch to the stellar-drift theme in the app, then use controls below.

2) Baseline Controls

Reports print in console as [StellarBaseline] Report.

3) Quick Manual Commands

window.stellarBaseline.play('default', { loops: 2, stepMs: 320 }); window.stellarBaseline.capture('stellar-hero-frame'); window.stellarBaseline.capturePack({ label: 'stellar-pack', defaultLoops: 2, stressLoops: 2 }); window.stellarBaseline.captureReadability({ label: 'stellar-readability' }); window.stellarBaseline.report(); window.stellarBaseline.downloadReport('stellar-baseline'); window.stellarBaseline.reset(); window.stellarBaseline.stop();
