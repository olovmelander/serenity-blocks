Chromadelic Highway Baseline + Soak Harness

1) Launch Runtime

After the app loads, switch to the chromadelic-highway theme in the UI. Then use the controls below.

2) Baseline Controls

Reports are printed in the embedded app console as [ChromadelicBaseline] Report.

3) Phase 6 Soak Controls

Uses window.chromadelicBaseline.runSoak(...) and reports memory/thermal trend stability.
Soak idle.

4) Phase 7 Signoff Pack

Captures hero frames + readability anchors and bundles baseline/budget/optional soak data.
Signoff idle.

5) Phase 7 Campaign Automation

Executes signoff captures for `Minimal -> Low -> Medium -> High -> Ultra -> Extreme`.
Campaign idle.

6) Functional Release Gate

Runs permutation smoke checks (`noMRT`, `noPost`, `noCompute`, forced WebGL) and theme-switch leak stress.
Release gate idle.

7) Quick Manual Commands

window.chromadelicBaseline.play('default', { loops: 2, stepMs: 260 }); window.chromadelicBaseline.capture('hero-frame'); window.chromadelicBaseline.capturePack({ label: 'hero', defaultLoops: 2, stressLoops: 2 }); window.chromadelicBaseline.captureReadability({ label: 'hero-readability' }); window.chromadelicBaseline.runSoak({ durationMinutes: 30, sampleSeconds: 30, stepMs: 220 }); window.chromadelicBaseline.getSoakReport(); window.chromadelicBaseline.downloadSoakReport('chromadelic-soak'); window.chromadelicBaseline.runSignoffPack({ defaultLoops: 2, stressLoops: 2, stepMs: 240, settleMs: 260 }); window.chromadelicBaseline.getSignoffReport(); window.chromadelicBaseline.downloadSignoffReport('chromadelic-signoff'); window.chromadelicBaseline.getPresetOrder(); window.chromadelicBaseline.report(); window.chromadelicBaseline.downloadReport('hero'); window.chromadelicBaseline.reset(); window.chromadelicBaseline.stop(); window.chromadelicHarness.runFunctionalSweep(); window.chromadelicHarness.runThemeSwitchStress({ cycles: 100, settleMs: 320 }); window.chromadelicHarness.getGateReport(); window.chromadelicHarness.downloadGateReport('chromadelic-release-gate'); window.chromadelicHarness.downloadGateMarkdown('chromadelic-release-gate');
