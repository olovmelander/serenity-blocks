Nimbus Veil Phase 0 Baseline Harness

1) Launch Runtime

After load, switch to the nimbus-veil theme in the app, then use controls below. Phase 0 note: Nimbus currently renders via WebGL path only; the forceWebGL run is recorded as a parity-matrix mode tag.

2) Baseline Controls

Reports print in console as [NimbusBaseline] Report.

3) Quick Manual Commands

window.nimbusBaseline.play('default', { loops: 2, stepMs: 300 }); window.nimbusBaseline.capture('nimbus-hero-frame'); window.nimbusBaseline.capturePack({ label: 'nimbus-phase0-pack', defaultLoops: 2, stressLoops: 2 }); window.nimbusBaseline.captureReadability({ label: 'nimbus-phase0-readability', settleMs: 280 }); window.nimbusBaseline.report(); window.nimbusBaseline.downloadReport('nimbus-phase0-baseline'); window.nimbusBaseline.stop();
