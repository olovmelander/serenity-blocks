1) Launch Runtime

Query defaults: moonlitBaseline=1&moonlitSeed=1234&moonlitFixedDt=16.666&moonlitPlayback=default&moonlitPlaybackLoops=1

2) Event Validation + Playback

  • Verify event responses retain gameplay semantics and timing.
  • Run once on WebGPU and once on forced WebGL fallback.
  • Check for visible response consistency during rapid sequence playback.

3) Resize + Theme Switch Stress

4) Soak (Current Quality)

Run this at each target preset/backend when collecting release evidence.

5) Medium/High/Ultra Soak Campaign

Uses helper quality switching + soak automation in sequence: Medium -> High -> Ultra.

6) Hero Frame + Preset Sweep

Preset sweep runs deterministic baseline checks across all presets on the active backend.

7) Evidence + Dual Backend Campaign

Evidence bundle captures metrics, event validation, tetromino validation, and optional frame capture. Dual campaign runs evidence on both backends and exports a comparison report.
