Stellar Velocity Phase 0 Baseline Harness

1) Launch Runtime

After load, switch to the stellar-velocity theme in the app, then use controls below.

2) Baseline Controls

Reports print in console as [StellarVelocityBaseline] Report.

3) Quick Manual Commands

window.stellarVelocityBaseline.play('default', { loops: 2, stepMs: 320 }); window.stellarVelocityBaseline.capture('stellar-velocity-hero-frame'); window.stellarVelocityBaseline.capturePack({ label: 'stellar-velocity-pack', defaultLoops: 2, stressLoops: 2 }); window.stellarVelocityBaseline.captureReadability({ label: 'stellar-velocity-readability' }); window.stellarVelocityBaseline.report(); window.stellarVelocityBaseline.downloadReport('stellar-velocity-baseline'); window.stellarVelocityBaseline.reset(); window.stellarVelocityBaseline.stop();
