# Odyssey Mode — Chapter-by-Chapter Improvement Plan

> One cohesive graded AAA film. Eight themed chapters, one camera, one journey. This doc is the executable bridge from "good in flashes" to "out of this world."

---

## 1. Vision & how to read this doc

Odyssey Mode is a single continuous camera-dolly down a spline through 8 themed chapters, rendered on three.js `WebGPURenderer` + TSL `NodeMaterial`s, finished with one ACES tonemap + threshold bloom + a master grade (tinted toe, soft shoulder, per-chapter signature tint/contrast/vignette/CA cross-faded on the seam). The visual overhaul (Phases A/B/C) already landed the *systems*: per-chapter colored fog lerped on seam, a corridor depth field, a unified path tube + mountain language, ecotone overlap transitions with a demoted portal ring, and the full post pipeline.

**Current overall state (the honest read):** The grade and the systems are sound — Mountains (ch4) and Space (ch6) prove the master stock sings when the *scene gives it a value range*. The remaining gap is **per-chapter scene value structure and composition**, not the pipeline. Three failure patterns recur: high-key washout that starves the grade (Deep Ocean, Sky), empty-black that starves it the other way (Black Hole mid-chapter), and local clipping in hot chapters (Earth Core orange slab, Urban white neon). The two flagship problems are **Deep Ocean** (flat "pool water," no dive, no hero — the top-priority remake) and **Black Hole** (empty black for ~75% of its run — the singularity is not an ever-present hero).

**How to read each chapter section:** Current state → Target theme/identity → Weaknesses → an Improvement table (`dimension | plan | impact | effort`) → Visual-direction notes → Files to touch. Then Transitions (the 7 seams), a prioritized execution roadmap grouped into conflict-free batches, and a Definition of Done.

## 2. Global cinematic grade & consistency

The master curve is **keepable as-is**. Calibrate everything toward two reference frames where the stock already works: **Mountains (ch4)** and **Space (ch6)**. The fix for every weak chapter is to give the *scene* the value structure those two have, then let the unchanged master curve grade it — **do not chase the look by cranking per-chapter tints** (that breaks "one film").

### Value / temperature arc (the journey's breath)

Temperature alternates warm/cool every beat for rhythm; value dips at the two introspective troughs (ch2, ch7) and peaks at the relief beat (ch3). The vignette arc already encodes this — make the *scenes* match it.

### Visual-direction guardrails (cross-cutting, non-negotiable)

| Guardrail | Rule |
|-----------|------|
| **No white blowout anywhere** | Clip sources are SCENE emitters, not the grade. Fix at three levels: per-chapter earlier shoulder knee (0.78–0.80 for hot chapters), **cap emissive path/node brightness to ~0.9 display at the material** (the path is in all 8 frames — its consistency is the through-line), and lower per-chapter saturation on Earth Core/Urban. The three brightest seams (surface-breach, cloud-break, atmosphere-rim) stay soft/tinted, never clip. |
| **Value-aware vignette** | Today `smoothstep(0.95,0.32,dist)` is a pure radial multiply — invisible on high-key (Ocean) and empty-black (Black Hole) frames. Add a **scene-luma-coupled term** so it darkens edges in proportion to local brightness. Then ch2's 1.28 and ch7's 1.05 finally focus the eye. |
| **Vignette focus** | Stronger in introspective troughs (ch2, ch7), lighter in open beats (ch4, ch5). Bump Urban → ~1.12 to anchor floating neon banks. |
| **Edge chromatic aberration (global)** | Keep the subtle edge-only character (`radialEdge = dist^2 * 2.4`, base ~0.0015) — reads as lens, never center haze. |
| **Black Hole lensing CA spike** | Chroma weight 1.9 is the journey's peak. Add `uChromaCenter` (vec2, default `0.5,0.5`) keyed each frame to the **singularity's screen-space position** during ch7, so fringing wraps the event horizon like real lensing. Requires the ever-present bright accretion rim (content) to act on. Smooth the center move on enter/exit. |
| **Soft accretion (no hard edges)** | Any disk/glow ring is a smooth radial falloff that lands BELOW bloom threshold at its body; only the thin hot rim crosses threshold to bloom. The void-glow floor is a very low smooth radial lift (under threshold) so it darkens-with-vignette rather than blooming. |
| **Split-tone convention ("one film")** | Cool-teal/indigo toe (`MASTER.toeTint`) + chapter-appropriate warm-or-cool highlights. Earth Core = warm highs / cool obsidian toe; Black Hole = warm accretion rim / cold void; Sky = warm sun / cool zenith; Ocean = neutral-cool highs / deep-teal toe. |
| **Performance** | Instanced + capped everywhere. Reuse shared `uTime`/`snoise3`/billboard helpers; no per-frame allocations (extend existing `_scratch`/`_sm` smoothed-state fields; signature additions follow the SAME seam lerp path via `_resolveChapterSignature`). All grade changes are scalar/vec uniform math on the existing single post pass — negligible cost. |

### Chapter 2 — Deep Ocean & Liquid Worlds 🏆 FLAGSHIP REMAKE (Top Priority)

> **The single most important section in this plan.** Diagnosis: this is a **composition + atmosphere-balance failure, NOT missing geometry.** The gradient sphere, god-rays, creatures, seabed and kelp all exist in `deep-ocean(.tsl).js` — they are washed flat and out of the camera's level sightline. Fix the camera framing and the flat additive haze FIRST and most of the existing work reappears for free.

**Current state.** A near-uniform pale-cyan "pool water" wash, top to bottom, with murky speckle that reads as flat noise. Only one frame (camera pitched down) shows any depth. Three compounding causes: **(1)** no chapter-2 entry in `CHAPTER_FRAMING_OVERRIDES`, so the camera looks LEVEL and only ever sees the gradient's pale-teal mid-band — never the bright top or dark abyss that sell a dive; **(2)** the corridor field ch2 particulate (`mote 170, 0x9fe8ff, additive, follow:true`) wraps the camera in pale-cyan additive haze + `FogExp2(0x06243f, 0.008)` on top — together they flatten the gradient sphere into a uniform wash; **(3)** god-rays originate high (y=55) and creatures sit z=-60..-220 / y=+18..-62 (above-behind and below a level camera) — out of the sightline.

Graded cool-teal highlights into deep-indigo shadow, never white; light always reads as **filtered, volumetric, refracted** — never flat speckle.

**Weaknesses.** No vertical depth gradient reads (level camera sees only mid-band); flat uniform wash buries gradient + set pieces; god-rays invisible (origin too high, drowned by haze); caustics read as flat noise not refracted light; no hero moment (creatures tiny/out of sightline); bioluminescence doesn't pop; seabed/reef only appears by accident of pitch; murky additive bubbles/plankton add noise not life.
