## Usage Tips for Suno AI

1. **Style Tags:** Add tags like `ambient`, `electronic`, `meditative`, `atmospheric`, `instrumental`
2. **Mood Tags:** Include `peaceful`, `serene`, `calm`, `relaxing`, `contemplative`
3. **Duration:** Request 2-4 minute tracks for seamless looping
4. **Instruments:** Specify `synth pads`, `soft drones`, `gentle arpeggios`, `ethereal textures`
5. **No Vocals:** Add `instrumental only` or `no vocals` if you want purely instrumental tracks
